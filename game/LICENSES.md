# Original project audio

`audio/music/dream.ogg` — **Sleep in the Base Camp**, Expedition project,
original procedural composition, 2026. Dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Generated offline by `scripts/dream-music.mjs`, using ffmpeg's oscillators and
Vorbis encoder. No external samples, recordings, or generative services.
The 60-second stereo loop uses D minor/add9, with frequencies and slow envelopes
chosen to complete whole periods at the boundary.
